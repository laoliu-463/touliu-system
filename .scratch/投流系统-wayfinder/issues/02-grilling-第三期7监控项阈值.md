## Question

第三期 7 监控项的"什么数据 + 什么阈值 = 触发告警"是怎么定的？每项要给一份**判定规则表**。

需求文档第三章 3-1 列了 7 项：

| # | 监控项 | 待定 |
|---|---|---|
| 1 | 监控标签 | 看哪些指标（消耗 / 转化率 / 曝光 / 点击）？标签用哪个分类？告警发哪个标签？ |
| 2 | 监控消耗 | 3 分钟消耗超过多少 / 增速超过多少触发？分账户预算占比触发？ |
| 3 | 监控状态 | 哪些状态算"异常"？新建 / 审核中 / 投放中 / 已下线 各自的告警价值？ |
| 4 | 广告审核建议 | 触发条件（疑似违规 1 次？3 次连续？）+ 推送内容 |
| 5 | 内容审核建议 | 同上，素材层 |
| 6 | 追投关停 | 哪些指标连续告警多少次自动关停？手动什么级别？ |
| 7 | 素材调控 | 素材消耗占比多少算"差素材"？多少算"好素材"？ |

**约束**：
- 先只告警、人点头后才执行（决策 #6）。这条 ADR 出来的"阈值表"只用于"触发告警"，不直接触发动手。
- 全局 3 分钟频率（决策 #14）。每账户 × 每监控项都要能被单独开关。
- 默认全关、人手动开（决策 #10）。

**期望产出**：`docs/adr/NNNN-监控阈值.md`，含 7 项的判定规则表 + 单账户配置默认值（如：消耗监控默认 3 分钟 ≥5 元触发）。
